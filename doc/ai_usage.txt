    Q: how to add package in verilog

    R: // rtl/conv_pkg.sv
    package conv_pkg;
        parameter int WIDTH = 16;
        parameter int ACCW  = 48;

        typedef logic signed [WIDTH-1:0] data_t;
        typedef logic signed [ACCW-1:0]  acc_t;
    endpackage

    import conv_pkg::*;          // whole package

    module mac (
        input  data_t input0,
        ...
    );
        acc_t acc;
    endmodule

    Q: Based on the power report, is the sum of the dynamic and static power the power used per cycle for 1 set of inputs

    R: Dynamic plus leakage is average power (energy per second), not energy per cycle an not energy for one input
    
    ---------------------------------------------------
    Q: Based on the timing report is the slack time the time for 1 set of input? 

    R: Slack is leftover (or missing) time in the clock period of the slowest path after the clock edge.
    
    ---------------------------------------------------
    Q: Then in the case of slack met(0), the time to complete 1 cycle of an input is the clock period that I used

    R: Yes. If slack is MET (critical path used the whole period), the chip can run at the clock you set. One cycle is that period.
    
    ---------------------------------------------------
    Q: Then to calculate the energy required, E = P_av(T(50)), where T(50) = (50 + i)t such that t is the period for slack = MET and i is adjusted/different value of the acutal cycle amount

    R: Yes

    Q: why is the critical path consistently from bit [0] to bit [47] of out\accum\reg in reg2

    R: In an adder, a change on the LSB can affect every higher sum bit. The MSB waits the longest, so STA reports [0] → [47].

    ---------------------------------------------------
    Q: what is the unit for the data arrived time and is that the required time of a single clock cycle 

    R: Not the clock period, the required time is the usable window inside a clock cycle after delay.
