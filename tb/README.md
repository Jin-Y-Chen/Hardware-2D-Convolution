Testbenches used by the simulator. Same part folders as `rtl/` (`part1/`, later part2–4). Synced to lab40 with `link` (`tb/README.md` is host-only).

**part1:** `mac_tb.sv`, `mac_tb.c`, `simParams1`, `params.sv`

`params.sv` is generated by `./simParams1 WIDTH ACCW PIPELINED` (3 args write only; 4 args also compile and run). `vsim mac_tb` on the host calls that script when the compile set is part1.
